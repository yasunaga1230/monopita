# モノピタ（MonoPita）- 要件定義書

> あなたにぴったりのモノが見つかる — 暮らしの便利グッズ＆ガジェット情報サイト

## 1. プロジェクト概要

### サイト名
**モノピタ**（MonoPita）
- キャッチコピー: 「あなたの暮らしに、ぴったりのモノを。」
- ドメイン: monopita.com（または monopita.jp）

### 成果目標
「暮らしの便利グッズ＆ガジェット」に特化したアフィリエイトブログサイト。AIが毎日自動で記事を生成・Amazon商品リンクを挿入・サイトに公開する。初期セットアップ後は完全放置で運用できる。

### 成功指標

**定量的指標:**
- 毎日1記事の自動投稿（月30記事）
- 記事あたり1,500〜3,000文字
- 1記事あたりAmazon商品リンク3〜5個
- 運用作業ゼロ（完全自動）

**定性的指標:**
- 購入意欲を創出する高品質なデザイン
- 検索上位を狙えるSEO構成
- 押し売り感のない自然な商品紹介

### 収益モデル
| 方法 | 仕組み |
|------|--------|
| Amazonアソシエイト | 記事内商品リンク経由の購入で報酬 |
| Google AdSense | PVに応じた広告表示報酬 |

## 2. システム全体像

### アーキテクチャ

```
GitHub Actions (cron: 毎日JST 11:00)
  │
  ├─ 1. generate-article.ts 実行
  │    ├─ 季節・日付・カテゴリバランスを考慮してテーマ決定
  │    ├─ Gemini APIで記事Markdown生成
  │    │    ├─ SEOタイトル・メタディスクリプション
  │    │    ├─ 見出し構成（H2/H3）
  │    │    ├─ 本文（1,500〜3,000文字）
  │    │    └─ Amazon商品リンク（3〜5個、tag付きURL）
  │    └─ src/content/posts/YYYY-MM-DD-slug.md として保存
  │
  ├─ 2. git commit & push
  │
  └─ 3. Cloudflare Pages が自動検知してビルド・デプロイ
```

### 機能一覧
| # | 機能 | 説明 |
|---|------|------|
| F-001 | 記事一覧表示 | 最新順の記事カード一覧。カテゴリフィルタ付き |
| F-002 | 記事詳細表示 | Markdown記事のレンダリング。目次・関連記事 |
| F-003 | Amazon商品リンク表示 | 商品カード形式で自然に埋め込み |
| F-004 | AdSense広告枠 | 記事内・サイドバーに広告表示 |
| F-005 | SEOメタ情報 | OGP・構造化データ・sitemap.xml自動生成 |
| F-006 | AI記事自動生成 | GitHub Actionsで毎日実行 |
| F-007 | カテゴリ分類 | デスク周り・キッチン・掃除・スマホ・季節アイテム等 |

### ロール
- **サイト閲覧者**（ゲスト）: 全ページ閲覧可
- **管理者**: なし（GitHub経由で管理）

### 認証要件
なし（公開ブログのため認証不要）

## 3. ページ詳細仕様

### P-001: トップページ（記事一覧）

**ページID:** P-001
**ルート:** `/`
**目的:** 最新記事の一覧表示。サイトの入口としてSEO流入を受け止め、記事への回遊を促す

**機能:**
- 記事カード一覧（サムネイル・タイトル・概要・日付・カテゴリタグ）
- カテゴリフィルタ（タブまたはタグ形式）
- ページネーション（1ページ12記事）
- ヒーローセクション（サイト名・キャッチコピー）

**デザイン要件:**
- カラーパレット: ホワイト基調 + アクセントカラー（ティールグリーン #0D9488）
- 商品写真が映える明るくクリーンなデザイン
- カード型レイアウト（3カラム→タブレット2カラム→モバイル1カラム）
- カードにはサムネイル・タイトル・概要2行・日付・カテゴリバッジ
- モバイルファースト（レスポンシブ対応）
- ヒーローセクション: サイト名「モノピタ」+ キャッチコピー + カテゴリナビ
- フォント: Noto Sans JP（本文）、見出しはやや太め（600-700）
- 全体的にミニマルで余白を活かした洗練されたトーン

### P-002: 記事詳細ページ

**ページID:** P-002
**ルート:** `/posts/[slug]`
**目的:** 記事本文と商品リンクを表示。収益発生の核となるページ

**機能:**
- 記事本文レンダリング（Markdown → HTML）
- 自動生成の目次（H2/H3から生成、サイドバーまたは記事上部に配置）
- Amazon商品リンク: ハイブリッド型（後述）
- 関連記事セクション（同カテゴリの記事3〜4件）
- SNSシェアボタン（X・LINE・はてブ）
- AdSense広告枠（記事上部・中間・下部の3箇所）
- パンくずリスト（ホーム > カテゴリ > 記事タイトル）
- 公開日・更新日表示
- 前後の記事へのナビゲーション

**デザイン要件:**
- 読みやすいタイポグラフィ（本文16px、行間1.8、最大幅720px）
- カラーパレット: トップページと統一
- 見出し（H2）に左ボーダー + アクセントカラーで視覚的区切り
- 記事の読了率を高める適切な余白と区切り
- モバイルでの読みやすさを最優先

**商品リンク仕様（ハイブリッド型）:**
- **インライン型（本文中）**: 記事の自然な文脈で商品名にテキストリンクを設置。読み手の流れを止めない
- **商品カード型（各商品紹介セクション末尾）**: コンパクトなカードブロックで購入導線を明確化
  ```
  ┌──────────────────────────────────────┐
  │ 📦 商品名                             │
  │ ¥2,980  ★★★★☆ (4.2)                │
  │ 一言説明テキスト                       │
  │              [Amazonで見る →]         │
  └──────────────────────────────────────┘
  ```
- カードのデザイン: 薄いボーダー + 背景色（gray-50）、ホバーで軽い影
- CTAボタン: Amazonオレンジ（#FF9900）で視認性確保
- 1記事あたり3〜5個の商品カードを配置

### 固定ページ（AdSense審査用）

**P-003: プライバシーポリシー** (`/privacy`)
- Cookie使用、AdSense・Amazonアソシエイト利用の明記

**P-004: お問い合わせ** (`/contact`)
- Googleフォーム埋め込み（バックエンド不要）

**P-005: 運営者情報** (`/about`)
- サイト運営者情報・免責事項

## 4. データ設計概要

### 記事データ（Markdownフロントマター）

```yaml
---
title: "記事タイトル"
description: "メタディスクリプション（120文字以内）"
category: "desk" | "kitchen" | "cleaning" | "smartphone" | "seasonal" | "other"
tags: ["タグ1", "タグ2"]
pubDate: "2026-03-14"
heroImage: "/images/posts/YYYY-MM-DD-slug.webp"
products:
  - name: "商品名"
    asin: "B0XXXXXXXXX"
    price: "¥2,980"
    description: "商品の一言説明"
    rating: 4.2
---
```

### カテゴリ定義

| ID | カテゴリ名 | slug |
|----|-----------|------|
| C-001 | デスク周り・PC周辺 | desk |
| C-002 | キッチン便利グッズ | kitchen |
| C-003 | 掃除・収納 | cleaning |
| C-004 | スマホ・モバイル | smartphone |
| C-005 | 季節アイテム | seasonal |
| C-006 | その他暮らし | other |

### バリデーション
- title: 必須、60文字以内
- description: 必須、120文字以内
- category: 必須、定義済みカテゴリのみ
- pubDate: 必須、ISO 8601形式
- products: 1記事あたり3〜5件

## 5. セキュリティ要件

**CVSS 3.1準拠**

### 全プロジェクト必須
- ヘルスチェックエンドポイント: 不要（静的サイトのため）
- HTTPS強制: Cloudflare Pagesで自動対応
- 入力値サニタイゼーション: Markdownレンダリング時のXSS対策（Astro標準で対応）

### 静的サイト固有
- APIキーはGitHub Secretsに格納（リポジトリコードに含めない）
- CSP（Content Security Policy）ヘッダーの設定
- 外部スクリプト（AdSense）のIntegrity確認

## 8. 記事自動生成仕様

### 生成パイプライン

**実行タイミング:** 毎日UTC 02:00（JST 11:00）

**生成ロジック:**
1. 過去記事のカテゴリ分布を分析し、偏りが少ないカテゴリを優先
2. 季節・月（3月→新生活、7月→夏対策 等）を考慮したテーマ選定
3. Gemini APIに以下を指示:
   - SEO最適化されたタイトル（32文字以内）
   - メタディスクリプション（120文字以内）
   - H2/H3の見出し構成
   - 本文1,500〜3,000文字
   - Amazon商品の推薦（商品名・ASIN・概算価格・一言説明を3〜5件）
   - 自然な導入・まとめ
4. Markdownファイルとして `src/content/posts/` に保存
5. git commit & push
6. Cloudflare Pages自動デプロイ

### プロンプト設計方針
- PREP法（結論→理由→具体例→結論）で構成
- 「実際に使ってみた」風の体験ベース記述
- 押し売り感を排除し、メリット・デメリットを公平に紹介
- 各商品にAmazonリンクを自然に配置

### 画像戦略
- ヒーロー画像: Unsplash APIまたはフリー素材を活用（初期はプレースホルダー）
- 商品画像: Amazon商品ページへのリンクで代替（著作権配慮）
